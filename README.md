# Student-Management-Analysis-System
Developed using Python, Pandas, and NumPy. Managed student records through a menu-driven application. Performed performance analysis using statistical calculations and tabular reporting. Stored and processed student data using CSV files.
## Technologies Used
- Python
- Pandas
- NumPy
## Features
- Add Students
- View Students
- Performance Analysis
- Store data in CSV file
